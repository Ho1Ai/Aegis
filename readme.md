# AEGIS
Aegis is a small project. Will be updated soon  
## Installation
Now it is possible only to use installations using git clone, make and sudo cp ./build/aegis /usr/local/bin/aegis. As soon as this project is ready at least on 30% it will be uploaded to AUR
## Languages
We use C++ here, because in some places we need destructors in order to leave heap problem on segfault behind. This code also will be ported to C by me as soon as it will be ready, but not now, because we started this project as our personal project in one language all of us know. Also one of the contributors doesn't know C, so it would be a little bit harder to make C code work if one of us doesn't know how to work with most functions, except malloc() and realloc()
## TUI
It uses RAW mode, so there is some specific stuff here. We're gonna add a lot of stuff, so follow us!
